# オリジナルカード作成アプリ
オリジナルデザインのカードを、ブラウザ上で作成できるアプリです。  
好きな画像や名前、コスト、属性、スキルなどを入力してカードを作成できます。

## できること
・カードテンプレートを選択  
・カード名を入力  
・カード名の文字サイズを調整  
・コストを入力  
・属性 / 種族を入力  
・スキルを入力  
・カード画像をアップロード  
・オリジナルカードをPNG画像として生成  

## 使い方
1. カードのテンプレートを選択  
2. カード名やコストなどを入力  
3. カードに使用する画像をアップロード  
4. カードを生成して完成したカードを確認  
5. 必要に応じて画像を保存

## このアプリについて
このアプリは、Pythonの学習を兼ねて制作しています。  
子どもが考えたオリジナルカードを、実際にカード画像として作成できるようにすることを目的として制作しました。  
カードのテンプレートは、子どもが考えたデザインをもとに作成しています。
